# Rolling Dice

Vanilla JavaScript dice simulation that displays roll results as a bar chart, with two HTML versions of the UI.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure
```
rolling-dice/
├── index.html         # Version 1
├── index2.html        # Version 2
└── app.js
```

## Development
No installation required. Open either HTML file directly in a browser:
```bash
open rolling-dice/index.html
```

## Key Notes
- No build step or dependencies — self-contained static files.
- Bar chart is rendered with pure DOM manipulation.
